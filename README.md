# PR Reviewer Assignment Service

Решение тестового задания: сервис для назначения ревьюверов Pull Request'ов. Написан на Go и PostgreSQL. Архитектура достаточно простая.

## Как запустить

### Через Docker Compose

1. В репозитории уже есть `docker-compose.yml`, который поднимает и API, и PostgreSQL.
2. Просто запускаешь:
   ```
   docker compose up --build
   ```

Сервис доступен по адресу `http://localhost:8080`, база — `localhost:55432` (логин/пароль `postgres/postgres`, база `postgres`).

## Остановка

```
docker compose down
```

Схема БД создаётся автоматически при старте приложения, поэтому отдельные миграции не нужны.

### Статистика

Добавил вспомогательный эндпоинт `GET /stats`, который возвращает:
- `reviewers` — сколько раз каждого пользователя назначали ревьювером;
- `pull_requests` — сколько ревьюверов у каждого PR.

### Линтер

Я использовал `golangci-lint`. Нужно поставить его локально (`brew install golangci-lint`). Для проверки достаточно запустить:
```
make lint
```
Конфигурация лежит в `.golangci.yml`, там оставил только базовые линтеры (`govet`, `staticcheck`, `unused`).

### Нагрузочное тестирование

Для проверки времени ответа и RPS прогнал `hey` по безопасному эндпоинту `/health`.

```
~/go/bin/hey -z 15s -c 10 http://localhost:8080/health
```

Что получилось:
- Средняя задержка ~ 1.0 ms, p95 ~ 1.8 ms.
- Средний запрос/секунда ~ 10.2k.
- Все 153k ответов вернулись с кодом `200`.

Тест запускал на личном ноутбуке с запущенным через Docker Compose сервисом. Ресурсов хватило, CPU заметно не проседал, так что считаю результаты достаточными для данного тестового стенда.

## Вопросы и проблемы и как я их решал

1. **Хотел проверять reassign, но в командах не хватало активных ревьюверов.**  
   Сначала включил дополнительных людей через `/users/setIsActive`, позже добавил новых пользователей. После этого `reassign` заработал, потому что в команде появились кандидаты.

2. **Проверка бизнес ограничений.**  
   В Postman сделал набор запросов (create, merge, reassign, getReview), чтобы руками убедиться, что:
   - PR создаётся и автоматически назначает до двух ревьюверов;
   - merge идемпотентен;
   - reassign запрещён после merge или если пользователь не назначен;
   - пользователю не выдаются PR, если его нет в системе.

3. **Падал линтер.**  
   Линтер падал из‑за того, что golangci-lint 2.6 требует явного `version` в конфиге. Добавил .golangci.yml с `version: 2`, базовыми линтерами (`govet`, `staticcheck`, `unused`) и отключил errcheck.
